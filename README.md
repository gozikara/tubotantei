# ツボ刑事 — 解剖・経穴バトル 🕵️‍♂️

症状モンスターと戦いながら、**筋肉(解剖)** と **経穴(ツボ)** をスマホで遊んで学べる、ポケモン風の学習ゲームです。無資格のセラピスト・整体師さんの実用知識の習得を想定しています。

## ゲームの4要素

| 要素 | 内容 |
|------|------|
| 🗺 **マップ探索・ストーリー** | 身体のエリアごとに「症状の事件」が発生。患者さんの物語を読んで捜査を開始 |
| ⚔️ **バトル** | 症状モンスターにクイズで攻撃。正解=原因筋・ツボを見抜く一撃。HPを削って鎮める |
| 📖 **収集・図鑑** | 解決するたびに、原因筋(起始・停止・作用)と経穴(位置・効果・注意)が図鑑に登録される |
| 💪 **育成・レベルアップ** | 経験値でレベルアップ→捜査ポイントを「診断眼(与ダメ増)」などに割り振って強化 |

進捗はスマホの `localStorage` に自動保存されます。

## スマホでの遊び方(PWA)

1. スマホのブラウザで `index.html` を開く(下記デプロイ参照)
2. Safari/Chrome の共有メニューから **「ホーム画面に追加」**
3. アイコンから起動すると、アプリのように全画面&オフラインで遊べます

## エピソード(事件)の増やし方

`js/data.js` の `window.EPISODES` 配列に1件足すだけでゲームが増えます(現在 EP1〜3 収録)。既存のエピソードをコピーして値を書き換えるのが簡単です。

`admin.html`(エピソード制作ツール)でプロンプトを生成 → claude.ai で台本・クイズを作り → `js/data.js` の形式に合わせて追記、という運用ができます。1件に必要なフィールド:

- `ep` / `title` / `location` / `mapPos:{x,y}` … 事件番号・タイトル・マップ上の位置(%)
- `patient` … 患者(名前・年齢・性別・職業・絵文字)
- `symptom` / `trigger` / `gaveup` … 主訴・きっかけ・諦めたこと
- `monster` … 症状モンスター(名前・絵文字・登場セリフ)
- `muscle` … 原因筋(名前・読み・解説) ← 図鑑に登録
- `acupoint` … 経穴(名前・読み・経絡・位置・圧し方・注意・効果) ← 図鑑に登録
- `script` … 会話劇([{speaker, text}]、speaker は narrator / patient / detective / monster)
- `quiz` … クイズ([{q, choices, answer(正解index), explain}])。正解1つ=1ダメージで、全問正解すると確実に撃破できます

> モンスターのHPはクイズの問題数から自動計算されます。過半数正解で事件解決です。

## 公開(GitHub Pages)

このリポジトリは静的ファイルだけで動きます。GitHub の **Settings → Pages** で対象ブランチを選ぶだけで、`https://<ユーザー名>.github.io/tubotantei/` として公開できます。ビルド不要です。

## ファイル構成

```
index.html     ゲーム本体(画面・ロジック)
js/data.js     エピソードデータ(ここを増やす)
manifest.json  PWA設定
sw.js          オフライン用 Service Worker
icons/         アプリアイコン
admin.html     エピソード制作ツール(プロンプト生成)
```
